Frequently asked questions

Is my text uploaded to a server?

No. The comparison runs entirely in your browser with the open-source jsdiff library, so your text never leaves this page — nothing is uploaded or stored anywhere.

How does the diff work?

The tool compares your texts line by line using a longest-common-subsequence algorithm. Lines only in the changed text are marked as additions, lines only in the original as deletions, and identical lines as unchanged.

What if the diff library fails to load?

This page ships with a built-in fallback line-diff (plain JavaScript, no network needed), so comparisons keep working offline or if the CDN is unreachable — the diff results are identical.
