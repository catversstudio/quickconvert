Frequently asked questions

Is the original layout, formatting and images preserved?

No — and we want to be upfront about it. This is a text-based conversion: every page's text is extracted and placed into the .doc file in page order. Layout, fonts, columns, tables and images are not carried over. It is perfect for editable text, quotes and documents you want to retype-free.

Is my PDF uploaded to a server?

No. The PDF is read with the pdf.js library loaded in your own browser, and the .doc is built and downloaded locally. Your file never leaves this page — nothing is uploaded or stored anywhere.

Which files can I convert?

Any single PDF up to 25 MB, including text-based PDFs. Scanned or image-only PDFs contain no selectable text, so the .doc would come out nearly empty for those — an OCR tool is needed for scanned pages.
