Frequently asked questions

How are commas inside quoted fields handled?

Correctly, per the RFC-4180 CSV standard: a field wrapped in double quotes may contain commas, line breaks and even escaped double quotes ("" becomes ") without breaking the column layout.

What does the "First row is header" option do?

When on, the first row becomes the keys of each JSON object (e.g. {"name": "Asha"}). When off, you get a plain array of arrays instead.

What do the row-number warnings mean?

They flag rows whose column count differs from the first row — usually a missing comma or an unclosed quote. The conversion still runs; fix the flagged rows for perfect output.
