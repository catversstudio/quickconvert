Frequently asked questions

Which ICO entries can be converted?

PNG-compressed entries (the modern standard) convert losslessly. 32-bit and 24-bit BMP entries are decoded too. Very old 1/4/8-bit paletted BMP entries are flagged as unsupported rather than converted incorrectly.

Why does my .ico have multiple sizes?

An .ico is a container — it bundles the same icon at several sizes so Windows and browsers can pick the sharpest one for each use. This tool lists every entry it finds.

Is my icon uploaded anywhere?

No. Parsing the ICONDIR headers, decoding entries and packing the ZIP all run locally in your browser.
