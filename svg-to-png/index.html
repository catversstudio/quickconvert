Frequently asked questions

Why did I get an "invalid SVG" error?

The code is checked with a real XML parser. Common causes: unclosed tags, mismatched quotes, pasting HTML instead of SVG, or an SVG with no width/height and no viewBox. Fix the markup and try again.

Will transparency be kept?

Yes. The SVG is rasterized onto a transparent canvas, so transparent regions stay transparent in the PNG.

Can SVGs with external images be converted?

No — for security reasons browsers block external references when rasterizing SVG. Inline all images as data URIs first.
