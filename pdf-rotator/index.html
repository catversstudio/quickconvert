Frequently asked questions

Is my PDF uploaded to a server?

No. The rotation happens with the pdf-lib library running locally in your browser, so your file never leaves this page — nothing is uploaded or stored anywhere.

Does rotating reduce the quality of my PDF?

No. Rotation only changes each page's rotation flag — the text, images and layout are untouched, so there is zero quality loss and the file stays a searchable PDF.

Can I rotate only some pages?

Yes. Choose "Page range" and enter something like 2-5 (or a single page like 3). Page numbers start at 1. Picking "All pages" rotates the whole document.
