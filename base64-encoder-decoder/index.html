Frequently asked questions

Is my text uploaded to a server?

No. Encoding and decoding happen entirely in your browser using the built-in btoa/atob and TextEncoder APIs — your text never leaves this page.

Does it handle emojis and non-English text?

Yes. Input is first encoded as UTF-8 before Base64 conversion, so emojis, Hindi, Odia, and any other Unicode text round-trips correctly.

What happens if I paste invalid Base64 in Decode mode?

The tool checks the input first and shows a friendly error message instead of decoding garbage — nothing breaks, and you can fix the input and try again.
