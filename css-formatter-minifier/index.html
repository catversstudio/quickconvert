Frequently asked questions

Does formatting or minifying change how my CSS works?

No. Formatting only changes whitespace and indentation, and minifying removes comments and unneeded whitespace — every rule, value and selector stays exactly the same, so your styles render identically.

How much smaller can minifying make my CSS?

Most stylesheets shrink by 20–40%. The tool removes comments, collapses whitespace and drops the last semicolon in each block, while safely keeping spaces inside strings and calc() expressions intact.

Is my CSS uploaded to a server?

No. Formatting and minifying run entirely in your browser (the formatter library loads once from a public CDN). Your CSS never leaves this page — nothing is uploaded or stored anywhere.
