Frequently asked questions

Is my image uploaded to a server?

No. The conversion uses your browser's built-in FileReader API, so your image never leaves this page — nothing is uploaded or stored anywhere.

What exactly is a base64 data URL?

It is the image's binary data encoded as plain text, starting with a prefix like data:image/png;base64,. Data URLs let you embed an image directly inside HTML, CSS or JavaScript without a separate image file.

Why is the base64 string larger than the original file?

Base64 encodes every 3 bytes of data as 4 text characters, so the output is about 33% larger than the original image. That is normal — it works best for small images like icons and logos.
