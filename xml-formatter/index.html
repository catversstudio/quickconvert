Frequently asked questions

Is my XML uploaded to a server?

No. Parsing and formatting run entirely with your browser's built-in DOMParser — your XML never leaves this page, and nothing is uploaded or stored anywhere.

What happens if my XML is invalid?

You get a friendly error box showing exactly what went wrong, taken from the parser's own message — usually an unclosed tag or a bad character — so you can fix it and try again.

Does minifying change my XML's meaning?

No. Minify only removes whitespace-only text between tags, so the document structure and all real text content stay exactly the same — just more compact.
