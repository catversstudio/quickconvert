Frequently asked questions

What Markdown is supported?

Headings, bold, italic, strikethrough, bullet and numbered lists (including nested), links, inline code, fenced code blocks, blockquotes, basic tables and horizontal rules.

Is it safe to paste Markdown containing HTML or scripts?

Yes. Any raw HTML in your input — including <script> tags — is escaped into harmless text and never executed or rendered. The output contains only tags generated from Markdown syntax.

Why hand-rolled instead of a Markdown library?

No CDN or external dependency means the page works offline, loads instantly and keeps your text 100% on your device. The parser covers the everyday Markdown most people actually use.
