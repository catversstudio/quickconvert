Frequently asked questions

Will this change my original PDF?

No. The tool creates a new copy of your PDF with the numbers stamped on each page. Your original file on your device stays untouched.

Can I start numbering from a page other than 1?

This tool numbers pages sequentially from 1. If you need a custom start number, that option is planned for a future update.

Is my PDF uploaded anywhere?

No — numbering happens entirely in your browser with the pdf-lib library, so your PDF never leaves this page.
